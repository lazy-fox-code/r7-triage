Отчёт о проверке

Метрики собираются автоматически, ручные проверки отмечаете вы. Отметки сохраняются сразу — страницу можно закрыть и вернуться. Файл отчёта содержит только числа, флаги и названия полей.

Комментарии попадают в файл как есть — не пишите в них адреса, имена и темы писем.
