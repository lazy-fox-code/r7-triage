# Проверка качества

`labeled.jsonl` в репозиторий не коммитится: это реальная переписка.
Файл создаётся локально, формат — по объекту на строку:

```json
{"messageId": "...", "subject": "...", "label": "task|info|noise", "note": ""}
```

Размер выборки: 300 писем, отобранных случайно по всему ящику, а не
из одной папки. Размечать вручную, до запуска модели.

Метрики считать по каждому классу отдельно. Общая accuracy бесполезна:
классы сильно несбалансированы.

Порог, ниже которого архивирование не включать: precision на классе
`info` не ниже 0.95.
